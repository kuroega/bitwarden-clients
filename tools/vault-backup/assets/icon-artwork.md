## Original generation prompt

+Use case: logo-brand
Asset type: production Windows desktop app icon for a backup utility, one square icon only.
Primary request: design a completely original refined icon inspired by Japanese Heian-period yamato-e illustrated scroll artwork. Rounded-square deep indigo lacquer-like tile with genuinely transparent outer corners. Central bold ivory rolled manuscript/archive scroll with vermilion binding, a graceful broad gold cloud ribbon curling around it suggesting preservation and return. Restrained ivory, antique gold, vermilion and indigo palette. Stylized hand-painted mineral-pigment elegance, simplified large silhouettes, exceptionally readable at 32 pixels, premium polished flat icon. Very subtle painted texture, no tiny ornament. Straight-on view, centered, tile fills 94 percent of square canvas with generous corner radius about 22 percent. Crisp edges, no external shadow. The scroll should look like a stored scroll, not an open fan.
Constraints: actual alpha transparency outside rounded square; no text, no letters, no watermark, no mockup, no multiple icons. Absolutely no hiogi, hinoki folding fan, folding fans, hand fans, or fan-shaped motif. No shield, no Bitwarden logo. Output single finished icon.
